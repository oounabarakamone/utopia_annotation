# ユートピア注釈アプリ

## ファイル構成

- `index.html`：表示するページ本体
- `notes.json`：語句ごとの解釈データ
- `script.js`：語句をタップした時に注釈を表示する処理
- `style.css`：見た目

## 使い方

PCなら、このフォルダを開いて `index.html` をダブルクリックしてください。

iPhoneだけで使う場合は、Kodex / Textastic などのコードエディタに4ファイルを同じフォルダへ入れてください。
ただし、iPhoneのローカル表示では `notes.json` の読み込みが制限される場合があります。
その場合は GitHub Pages / Netlify / Vercel などで公開すると安定して動きます。

## 注釈を追加する方法

`notes.json` に項目を追加します。

例：

```json
"新しい語句": {
  "aliases": ["新しい語句", "別表記"],
  "title": "新しい語句",
  "body": "ここに意味を書く。"
}
```

`aliases` に入れた語句が本文に出てくると、自動でタップ可能になります。
